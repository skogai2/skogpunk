# Skogai RPG — Android Arcade Edition

A cyberpunk terminal RPG and hacker trivia arcade rebuilt natively for Android using Kotlin and Jetpack Compose.

## Features
- **Arcade Runner**: Solve command-line trivia, bash scripting one-liners, cron configurations, and cybersecurity contracts.
- **Four Distinct Cabinets**:
  - **Sudo Hero** (Violet): Rise of the root user — automation and permissions triage.
  - **Wi-Fi Wizards** (Magenta): Signal sorcery — ARP scanning, default gateway discovery, and network debugging.
  - **Honkers & Hackers** (Cyan): Operation Skogai — HTTP header inspections and penetration testing.
  - **Skog-Net Syndicate** (Acid Green): City-Forest link — WireGuard encrypted tunneling and base64 packet decryption.
- **Real-Time Crew Simulation**: Local party mode with AI crew hackers (Skogix, Kenji) locking in answers in parallel and competing on the MVP leaderboard.
- **Append-Only Event Store**: Real-time log stream echoing the `events.jsonl` architecture.
- **Retro CRT Aesthetics**: Dynamic neon theme switching, glow plaques, and optional CRT scanlines overlay.
- **Adaptive Launcher Icon**: Custom adaptive cyberpunk terminal badge icon.

## Tech Stack
- Android 16 (API 36)
- Kotlin + Jetpack Compose + Material 3
- Modern MVVM Architecture with Flow and StateFlow
- Custom pixel fonts and retro CRT rendering
